Extract the current R6B reproducibility ZIP and numerical-record ZIP into the
same directory. Follow docs/release/S074_REPRODUCTION.md and the exact portable
test command in ARCHIVE_MANIFEST.json. Reproduction uses retained trajectories
and does not start new sampling. The scientific archive has a public-only PDF
build route; the private author delivery separately contains all four journal
PDFs, including the cover letter, and editable submission sources.

The raw-finest study already contained all 80 intervals; 78/80 met the stricter
design target. Paired Richardson estimates remove leading discretization bias
using the same stored paths. The chronology and two stricter misses remain
explicit. Earlier S-071 and S-073 studies remain unresolved and unpooled.

The exact decoder is confinement, directional order and kinetic content;
drift separates the tuned diffusion coincidence rather than entering that
three-coordinate signature. R6B improves exposition and numerical reporting,
not numerical records, registry margins or figure data.

Earlier releases and tags are preserved. MIT software licensing, CC BY 4.0
research text/data/figures, third-party notices, creator order and ORCIDs are
unchanged. This release is not a journal submission or journal acceptance.
